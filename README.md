# Tarea 3 - Desarrollo de Aplicaciones

Aplicación desarrollada como parte de la asignatura de Desarrollo de Aplicaciones. El proyecto fue realizado utilizando Ionic y React, creando diferentes pantallas y funcionalidades para practicar el desarrollo de aplicaciones móviles.

## Tecnologías utilizadas

* Ionic

* React

* TypeScript

* Vite

* HTML / JSX

* CSS

* Capacitor

## Funcionalidades

La aplicación cuenta con varias secciones y ejercicios:

* Página de inicio.

* Sección de experiencia personal.

* Operación de suma.

* Operación de multiplicación.

* Conversión de números a letras.

* Video de referencia integrado desde YouTube.

* Menú de navegación entre las diferentes secciones.

```
src/
```

## Instalación y Ejecución

Para ejecutar el proyecto localmente, primero se deben instalar las dependencias:

```
npm install

```

Luego se puede iniciar el proyecto con:

```
npm run dev

```

También se puede ejecutar utilizando Ionic CLI:

```
ionic serve

```

La aplicación estará disponible en la dirección local que muestre Vite o Ionic en la terminal.

### Uso

Después de instalar las dependencias y levantar el servidor, se puede navegar entre las diferentes opciones del menú para probar cada una de las funcionalidades.
